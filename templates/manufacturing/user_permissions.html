View = can see the page. Create = can add a brand-new one (e.g. a new Purchase Order). Edit = can modify one that already exists. Delete = can remove one. Unticked = no access at all - the page and its menu link won't show for this user. For most document types, Edit and Delete are only available while nothing has been built from that document yet (e.g. a Purchase Order can be freely edited or deleted until a GRN is raised against it; a Batch until work is sent on it) - once something downstream exists, editing narrows to safe details only (dates, remarks, transporter) and deleting is blocked with a message naming what's in the way. Reports and Stock views have no Create/Edit/Delete - only View applies to them.
